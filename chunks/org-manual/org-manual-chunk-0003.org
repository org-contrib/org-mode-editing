*** Using Org's Git repository
:PROPERTIES:
:UNNUMBERED: notoc
:END:

You can clone Org's repository and install Org like this:

#+begin_example
$ cd ~/src/
$ git clone ../../mirror/by-url/6c6c415dd9d527b20d824f0eea3d3f36f3edddbc67d7e08bf7ade3c795f8525e.git
$ # alternatively, you can use mirror
$ # git clone ../../mirror/by-url/997e54aef41f3f2f2b360ca4af86faff8dfd125ca455dd94feec91f607ae12d4.html
$ cd org-mode/
$ make autoloads
#+end_example

Note that in this case, =make autoloads= is mandatory: it defines
Org's version in =org-version.el= and Org's autoloads in
=org-loaddefs.el=.

Make sure you set the load path correctly in your Emacs init file:

#+begin_src emacs-lisp
(add-to-list 'load-path "~/src/org-mode/lisp")
#+end_src

You can also compile with =make=, generate the documentation with
=make doc=, create a local configuration with =make config=, and
install Org with =make install=.  Please run =make help= to get the
list of compilation/installation options.

For more detailed explanations on Org's build system, please check the
Org Build System page on [[../../mirror/by-url/8e57a64ab62f38f5533dc492c9652ee45622f5257b3360ac839b7a5ff8ea8019.html][Worg]].
